# BlueMap Entities
A native BlueMap addon, that renders all *vanilla* Mobs & Probs on your BlueMap!
This includes mobs like cows & villagers and probs like boats & minecarts.
Entity variants are fully supported!

**Note**: The entities are static and only move when bluemap updates

# Usage
In Fabric & NeoForge you can use BM-Entities as a normal mod, 
for paper (or other) place the jar into bluemaps `pack` folder (e.g.`plugins/bluemap/pack`).

To see the entities, BlueMap has to update the map (force full update with `/bluemap force-update`)
